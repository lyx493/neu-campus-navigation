# 东北大学浑南校区校园导航小程序

一个地图优先的微信小程序原型，包含实时定位、校园地点搜索、步行/骑行路线、转向提示、到达判定、收藏和系统地图接力。

## 直接运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件夹 `qinghe-campus`。
3. AppID 使用你自己的微信小程序 AppID；仅在模拟器体验时也可先使用测试号。
4. 编译后允许位置权限。真机调试时请开启系统“精确位置”。

项目已使用微信原生 `map` 组件，不需要额外地图 Key。

## 已实现功能

- 地图首页：实时位置蓝点、13 个浑南校区地点、分类筛选、地点搜索。
- 实时导航：`wx.startLocationUpdate` 持续获取位置，蓝色路线随位置更新。
- 步行 / 骑行：基于校园步道图计算最短路径和预计时间。
- 导航提示：直行方向、左转/右转、距离下一动作、剩余距离、预计用时、到达判定。
- 系统地图接力：一键调用微信内置地图导航，可继续切换到手机地图 App。
- 收藏、最近到访、地点详情、校园地址与开放信息。

## 数据说明

- 校区坐标：GCJ-02，校园中心约 `41.6531626, 123.4224780`。
- 步道网络：由 OpenStreetMap 校园步道数据简化生成，文件为 `data/walk-graph.js`。
- 校园 POI：图书馆、生命学馆、一号楼、一食堂、学生服务中心、五舍、研究生宿舍、风雨操场、校医院、南门、东门、西门等。
- 开放时间、设施和部分生活服务信息为界面示例，正式上线前建议由学校后勤或保卫处确认。

## 上线前建议

- 在微信公众平台配置位置隐私协议与用户隐私保护指引。
- 用学校官方校园地图复核校门和建筑的精确点位。
- 如果需要校外道路级的完整逐向导航，可将路线层替换为腾讯地图/高德地图 WebService，并申请对应 Key。
- 地图步道数据遵循 OpenStreetMap ODbL 许可，正式发布时保留数据署名。
