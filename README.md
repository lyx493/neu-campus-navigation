# 东北大学浑南校区校园导航 · 团队交付包

版本：**v16**  
日期：2026-10-20  
目标：验证“校园总地图 + 一号楼 1F/2F 标准化室内地图 + 室内导航 + 室外百度地图接力”的完整交互原型。

## 交付内容

| 目录 | 内容 |
| --- | --- |
| `web-app/` | 可直接运行的网页版，包含校园地图、定位、室内外导航、指南针、人工校准和百度地图跳转 |

## 网页版快速启动

### Windows

双击：

`web-app/start.bat`

然后访问：

`http://127.0.0.1:8765/`

也可以在该目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

### 手机测试

手机定位、方向传感器和运动传感器需要 HTTPS。本轮临时测试地址：

`https://shortcuts-garlic-rescue-physical.trycloudflare.com/?debug=1&v=20261020-16`

二维码文件：

`web-app/assets/mobile-test-qr.png`

临时 Cloudflare 地址可能失效，失效后需重新建立 HTTPS 隧道，不能作为正式线上地址。

## 已实现能力

- 东北大学浑南校区静态校园地图与 19 个校园地点
- 浏览器实时定位、地图自动居中和“我的位置”标签
- 一号楼 1F/2F 教室选择
- 从用户提供的原始楼层图生成标准化室内地图
- 室内到室内导航：同层直达、跨层经楼梯
- 室内到室外导航：教室 → 楼梯 → 1F → 出口
- 路线图蓝色路径、当前点、楼层切换和方向箭头
- 指南针、方向校准、方向正确/左右调整提示
- 人工位置修正：平面图点选、节点选择、±2 米微调、重新计步、步长切换
- 底部导航抽屉默认收起，可上拉展开、下拉收起
- 室内/室外常驻切换条
- 到达室外确认后跳转百度地图，并继续室外步行/骑行导航
- 诊断模式：权限、GPS、传感器事件、地图拖动、运行错误

## 核心限制

1. **浏览器没有真实室内坐标**。当前室内连续定位是“起点校准 + 指南针 + 步态推算”，误差会累计。
2. **无法读取蓝牙信标、UWB 或 Wi-Fi 指纹**，除非后续接入学校或第三方定位服务。
3. 教室路径和房间热点根据用户提供的平面图人工标定，走廊拓扑仍需用官方图纸复核。
4. 百度地图通过网页 URI 接力，不同手机可能打开百度地图网页或唤起 App，体验会有差异。
5. 临时 HTTPS 隧道只用于测试，不能用于正式生产。
