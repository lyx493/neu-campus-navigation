# 数据与坐标说明

## 坐标系

| 数据 | 坐标系 |
| --- | --- |
| OpenStreetMap 校园地图 | WGS84 |
| 浏览器 GPS | WGS84 / GCJ-02，取决于浏览器和设备 |
| 小程序 `wx.getLocation` | GCJ-02 |
| 百度地图 URI | BD-09 |

网页版会执行 WGS84 → GCJ-02 → BD-09 转换后再跳转百度地图。

## 校园地点

当前 `data.js` 包含约 19 个校园地点，包括：

- 图书馆、建筑学馆、信息学馆、文管学馆、生命学馆、一号楼
- 一食堂、瑞幸咖啡、学生服务中心
- 第一/第二/第三/第五学生宿舍楼、研究生宿舍楼
- 风雨操场、校医院
- 南门、东门、西门

部分开放时间、设施信息为演示数据，正式上线前应由学校确认。

## 室内数据

一号楼数据来自用户提供的两张平面图：

- `building1-1f.jpg`：一层，包含 A101-A109、B101-B125 等房间
- `building1-2f.jpg`：二层，包含 A201-A207、B201-B233 等房间

当前可点击房间热点和路线节点是人工标定的近似值，建议后续用学校官方 CAD/矢量图复核。

## 地图版权

- OpenStreetMap 数据遵循 ODbL
- 正式发布必须保留 OpenStreetMap 署名
- 学校平面图如来自学校资料，请确认内部使用与公开发布权限
