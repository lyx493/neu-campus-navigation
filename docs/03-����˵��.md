# 测试说明

## 桌面测试

1. 进入 `web-app/`
2. 双击 `start.bat`
3. 浏览器打开 `http://127.0.0.1:8765/`
4. 按 `F12` 打开控制台，可测试外部定位 API

## 手机测试

1. 使用固定 HTTPS 地址（GitHub Pages 或学校服务器）
2. 允许位置、方向与运动传感器权限
3. 点击底部“室内”
4. 点击“校准位置”
5. 选择一号楼 1F/2F 与实际教室
6. 确认位置，检查定位来源是否变为“人工校准”
7. 开始导航后检查当前位置是否在蓝色路线附近

## 外部定位测试

在浏览器控制台执行：

```js
window.CampusIndoorPositioning.update({
  floor: 2,
  x: 76,
  y: 86.8,
  accuracy: 0.8,
  source: 'uwb',
  roomCode: 'A203'
});
```

预期：

- 来源标签显示“UWB 实时定位”
- 平面图“我”点精确落在 `x:76%, y:86.8%`
- 跨层路线从 2F 楼梯阶段开始
- 再发送 1F 东南门附近坐标，导航切到 1F 出口门阶段

## 出楼测试

- 室内目的地为校园地点时，底部常驻“仍在室内 / 已到室外”
- 到达东南出口门后开始监听 GPS
- 用户确认后打开百度地图
- 百度地图路线应以当前点为起点、校园地点为终点

## 人工校准测试

导航中点击“修正位置”：

- 在平面图上点选实际位置
- 选择导航阶段节点
- 前后移动 2 米
- 重新计步

步数变化不应自动移动“我”点。

## 诊断

使用 `?debug=1`：

- 定位模式
- 定位来源
- 室内 x/y/楼层
- 外部定位最近更新时间
- GPS、方向、运动传感器事件
- JavaScript 错误
