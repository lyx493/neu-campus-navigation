# 已知问题与风险

以下问题应作为团队继续改进的重点，不应视为已完成生产能力。

## P0：室内连续定位不准确

- 浏览器无法读取真实室内坐标
- 仅依靠指南针和步态推算，误差会随距离累计
- 当前通过“吸附路线 + 人工校准 + 步长切换”缓解，但不能彻底解决
- 需要接入 UWB、蓝牙信标、Wi-Fi 指纹或学校已有室内定位服务

## P0：平面图不是官方矢量图

- 目前图层来自用户提供的 JPG 平面图
- 教室热点、走廊、楼梯位置是人工近似标定
- 路线可能穿过不存在的通道，必须用学校官方平面图或现场实测修正

## P1：楼层切换依赖人工确认

- 浏览器无法自动判断用户是否已经到达楼梯或已经下到 1F
- 当前通过“我已到楼梯，下一层”等按钮推进
- 后续可使用气压计、蓝牙信标或二维码节点自动判断

## P1：百度地图跳转体验不一致

- 通过网页 URI 接力，部分手机会打开网页版百度地图，部分会唤起 App
- 正式上线建议使用百度地图开放平台 Key 或移动端 Deep Link 方案
- 需在 iOS Safari、Android Chrome、微信内置浏览器分别回归

## P1：临时 HTTPS 隧道不可用于生产

- Cloudflare Quick Tunnel 无 SLA，重启后 URL 会变化
- 正式部署应使用学校服务器、域名和 HTTPS 证书

## P2：定位权限与浏览器差异

- iOS 必须由用户手势触发方向/运动权限
- 微信内置浏览器、Safari、Chrome 对传感器支持存在差异
- 部分设备没有绝对方向传感器，只能使用相对方向

## P2：缺少后端和数据管理

- 地点、教室、楼梯、路线均写在静态 JS 中
- 没有后台管理、版本管理、审核或数据统计
- 修改数据需要重新部署前端资源
