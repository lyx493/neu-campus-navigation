# 室内定位接口接入建议

建议新增统一定位接口，避免前端绑定某一种硬件。

```js
window.CampusIndoorPositioning = {
  update(position) {
    // position:
    // {
    //   buildingId: 'building1',
    //   floor: 2,
    //   x: 38.5,                // 平面图百分比坐标
    //   y: 42.0,
    //   roomCode: 'B215',       // 可选
    //   accuracy: 1.5,          // 米
    //   heading: 92,            // 正北为 0，顺时针
    //   timestamp: Date.now(),
    //   source: 'uwb' | 'ble' | 'wifi' | 'manual'
    // }
  }
}
```

## 接入步骤

1. 将外部坐标转换为当前标准化平面图的百分比坐标
2. 更新 `state.currentPlace`
3. 更新 `indoorGuide` 当前路线进度
4. 将 `state.accuracy` 显示到指南针/诊断面板
5. 保留人工校准作为异常兜底

## 诊断要求

每次外部定位更新应记录：

- 定位源
- 原始坐标
- 转换后坐标
- 精度
- 楼层
- 距上一位置的距离
- 是否发生楼层切换
