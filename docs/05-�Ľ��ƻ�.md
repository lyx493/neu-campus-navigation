# 下一阶段改进计划

## 第一阶段：完成坐标与平面图标定

1. 获取一号楼官方 CAD/PDF/矢量平面图
2. 核对所有教室、走廊、楼梯、卫生间和出入口
3. 为 1F/2F 各选至少 4 个控制点
4. 建立“真实米制坐标 ↔ 平面图百分比坐标”转换
5. 现场复核 A105 右侧东南出口门

## 第二阶段：接入真实室内定位

优先从以下方案中选择一种：

### UWB

- 厘米级精度
- 通过 WebSocket 直接调用 `CampusIndoorPositioning.connect`
- 需部署基站、标签和楼层标定

### BLE Beacon

- 部署在教室门口、楼梯和走廊拐角
- 建立 RSSI 指纹或三角定位
- 通过原生壳或小程序读取后注入网页

### Wi-Fi 指纹

- 与学校网络中心合作
- 建立离线指纹库
- 提供标准 API

没有上述基础设施时，只能做到“人工校准 + 路线提示”，不能宣称连续精准室内定位。

## 第三阶段：导航算法

- 偏航检测与重新规划
- 楼梯/电梯/无障碍路线选项
- 门、墙、不可通行区域约束
- 语音播报和震动提示
- 多建筑、跨楼栋路线

## 第四阶段：正式部署

- GitHub Pages 作为公开测试入口
- 学校服务器或固定域名作为正式入口
- 百度地图开放平台 Key 与合法域名
- 埋点、错误日志和版本管理
- iOS、Android、微信内置浏览器回归

## 建议分工

- 地图数据：官方图纸、控制点、门/楼梯标注
- 定位：UWB/BLE/Wi-Fi 接入、滤波、坐标系
- 前端：地图交互、导航状态机、移动端 UI
- 后端：定位服务、POI 管理、日志
- 测试：现场走测、设备矩阵、验收用例
