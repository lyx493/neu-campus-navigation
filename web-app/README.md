# 东北大学浑南校区导航网页版

## 打开方式

Windows 下双击 `start.bat`，浏览器会自动打开：

`http://127.0.0.1:8765/`

也可以在本目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/`。不要直接双击 `index.html`，浏览器通常不会在 `file://` 页面开放精确定位权限。

## 本次修复

- 地图不再在定位更新时强制回到当前位置。
- 用户拖动地图后自动进入“自由浏览”，不会自动回弹。
- 点击定位按钮或重新校准后，才恢复“跟随我的位置”。
- 地图拖动使用 `requestAnimationFrame` 帧节流，减少抖动。
- 增加持续 GPS 监听，而不是只读取一次位置。
- GPS 超时、权限被拒绝或精度较差时，自动打开室内定位并进入地图校准流程。

## 室内定位

浏览器无法直接读取 Wi-Fi 指纹或蓝牙信标，因此室内模式采用可落地的浏览器方案：

1. 打开右侧的“◎ 室内定位”。
2. 点击“校准位置”，在地图上点选自己所在的位置。
3. 点击“开启室内辅助”。
4. 手机允许方向与运动传感器权限后，通过指南针方向和步态检测更新位置。
5. 桌面浏览器没有运动传感器时，可用方向键或界面上的方向键移动演示位置。

当前室内选择器只开放一号楼 1F / 2F，教室编号使用 101-108、201-208 和公共设施点位作为演示数据；接入学校官方楼层图后可直接替换。

室内模式通过“起点校准 + 步态航位推算”工作。定位误差会随行走增加，建议每经过一个明确地标重新校准一次。

## 地图数据

- OSM 校园地图瓦片：z17，共 36 张
- 校园步道：OpenStreetMap，wgs84 坐标
- 地点：19 个校园地标
- 地图静态资源已本地化，不依赖外部地图 Key
## 手机测试

本轮测试使用临时 HTTPS 地址：

`https://shortcuts-garlic-rescue-physical.trycloudflare.com/?debug=1&v=20261020-9`

也可以在本地页面点击“手机测试”打开二维码。HTTPS 地址允许手机调用定位、方向和运动传感器。测试时先允许权限，然后从“体验室内定位”进入一号楼 1F/2F 标准化平面图。

“我的 → 手机诊断”可查看安全环境、GPS 精度、传感器事件数、地图拖动次数和运行错误，并可复制诊断信息。

## 室外导航接力

室内导航启动后，系统会监测是否离开一号楼范围。检测到出楼或获得稳定的室外 GPS 后，会自动跳转百度地图继续步行/骑行导航；导航页也保留“百度地图”按钮，可手动提前切换。


## 实时位置说明

导航启动后不会使用定时器自动移动位置。室内位置只由设备方向/步态传感器或手动方向操作更新；室外位置由 `watchPosition` 持续 GPS 更新。到达室外时显示确认弹窗，确认后跳转百度地图继续导航到终点。


## 室内/室外切换

导航开始后，底部面板常驻显示“仍在室内 / 已到室外”切换条，不遮挡路线和转向提示。检测到疑似出楼时，该切换条会高亮并震动提示；用户确认后才跳转到百度地图。


## 楼层级室内导航

室内导航会读取当前教室楼层，自动选择最近楼梯，依次提示“2F教室 → 2F楼梯 → 下到1F → 1F主走廊 → 楼门出口”。标准化楼层图会同步显示蓝色路线、当前位置和楼层标签，并提供“我已到楼梯，下一层”“我已到出口”手动确认按钮。


## 室内指南针

室内导航地图显示当前朝向、N 基准、路线方向箭头和“方向正确 / 向左调整 / 向右调整”提示。用户面向路线前进方向点击“校准方向”后，系统会修正设备指南针偏移；位置点只沿规划路线按实际步数推进，避免指南针漂移造成位置偏离。


## 室内到室内导航

目的地选择“一号楼”后，可展开室内子地点选择器，指定 1F/2F 教室。同层路线直接沿走廊前往；跨层路线先前往当前楼层最近楼梯，再上/下到目标楼层并前往目标教室。室内目的地不会触发百度地图切换。


### 室内子地点

目的地选择一号楼后，会显示 1F/2F 楼层和具体教室下拉框。同层路线沿走廊直达；跨层路线先到最近楼梯，再上/下楼层并前往目标教室。室内目的地不会弹出百度地图切换。


## 室内位置修正

浏览器无法获得真实室内坐标。导航中的“修正位置”允许用户选择实际所在的路线节点，并支持前后 2 米微调和重新计步。该操作会重置步态累计误差。连续高精度室内定位仍需 UWB、蓝牙信标或 Wi-Fi 指纹定位接口。


## 人工辅助定位

导航中的“修正位置”支持直接在标准化楼层图上点选实际位置，系统自动吸附到最近路线；还支持短/标准/长步长切换、前后2米微调和重新计步。人工校准后会重置累计步态误差。
