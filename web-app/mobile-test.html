手机扫码测试
室内导航与标准化地图

该地址为临时 HTTPS 链接，手机可直接调用精确定位、方向与运动传感器。

https://shortcuts-garlic-rescue-physical.trycloudflare.com/?debug=1&v=20261020-16-9
  1. 扫码打开页面，先允许位置、方向和运动传感器权限。
  2. 点击底部“室内”→“校准位置”，选择一号楼 1F 或 2F。之后在“导航→目的地→一号楼”展开室内子地点，选择 1F/2F 具体教室。导航中可用“修正位置”点选实际位置、切换短/长步长、前后微调或重新计步。
  3. 在标准化平面图上点击教室，例如 A101、B215，然后确认位置。
  4. 点击“开启室内辅助”，导航会显示标准化楼层图、蓝色路线、当前位置箭头和指南针。可按当前路线方向校准指南针，底部面板可下拉收起。
  5. 从“我的 → 手机诊断”打开诊断面板，复制或截图诊断信息。
临时隧道只用于本轮测试，关闭后会失效。室内定位采用校准点 + 方向/步态推算，楼层图已按你提供的 1F/2F 原始平面图转换为标准化地图。
