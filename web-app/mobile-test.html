手机扫码测试
室内导航与标准化地图

每次部署都会生成本次版本专属二维码，手机扫码后进入最新测试版本。

https://lyx493.github.io/neu-campus-navigation/?debug=1&v=20261021-8
  1. 扫码打开页面，先允许位置、方向和运动传感器权限。
  2. 点击底部“室内”→“校准位置”，选择一号楼 1F 或 2F。之后在“导航→目的地→一号楼”展开室内子地点，选择具体教室。导航中可用“修正位置”在平面图上点选实际位置，或前后微调 2 米。
  3. 在标准化平面图上点击教室，例如 A101、B215，然后确认位置。
  4. 点击“开启指南针”并允许运动传感器。导航开始后，手机方向和步数会沿规划走廊实时推进当前位置；可通过“修正位置”重新校准。
  5. 从“我的 → 手机诊断”打开诊断面板，复制或截图诊断信息。
室内实时位置由手机方向和步数沿走廊估算，并可由人工校准、二维码节点或外部 UWB / 蓝牙 / Wi-Fi 坐标纠正。传感器估算会漂移，定位来源会明确标注。
打开手机诊断入口返回导航
